# 📊 Sales Data Analysis & Dashboard — Power BI Evaluation

An end-to-end Business Intelligence project built in **Microsoft Power BI Desktop**. This repository showcases data ingestion, ETL data cleaning using **Power Query (M)**, custom data modelling with **DAX**, and interactive dashboard visualisations using a raw customer orders dataset (`SalesData_1000Rows_WithIssues_copy.csv`).

## 🎯 Project Objectives

1. **Data Cleaning & ETL (Power Query):** Audit, clean, deduplicate, and standardise raw CSV/Excel sales records before loading them into the data model.
2. **Data Visualisation (Report View):** Build interactive charts to analyse regional order distribution, top-performing products, and historical profit trends.
3. **DAX Modelling:** Create custom calculated tables, calculated columns, and dynamic measures to support deeper financial and regional reporting.

---

## 🧹 Step 1: Data Cleaning & Transformation (Power Query)

The raw dataset contained several data-quality anomalies that were resolved in **Power Query Editor** prior to loading:

* **Date Standardisation (`OrderDate`):** Converted text dates formatted as `DD-MM-YYYY` into a standard `Date` data type using the **English (United Kingdom)** locale, and filtered out records with missing (`null`) dates.
* **Duplicate Removal:** Identified and removed duplicate order entries based on unique **`OrderID`** values.
* **Missing Categorical Values:** Replaced blank/`null` entries in **`CustomerName`**, **`Region`**, **`Product`**, and **`Category`** with `"Unknown"` to preserve transaction counts during aggregation.
* **Numeric Imputation:** Repaired missing values in **`UnitPrice`**, **`Sales`**, **`Cost`**, and **`Profit`** using exact accounting relationships (`Sales = Quantity × UnitPrice` and `Profit = Sales - Cost`).

> 💡 *See `scripts/Transform_SalesData.pq` for the full reproducible Power Query M script.*

## 🧮 Step 2: DAX Calculations

Three custom DAX elements were added to the Power BI data model:

### 1. Calculated Table — `EastRegionOrders`
Filters the cleaned dataset to isolate orders originating exclusively from the **East** region.
```dax
EastRegionOrders = FILTER('SalesData', 'SalesData'[Region] = "East")
```

### 2. Calculated Column — `ProfitCostDifference`
Calculates the row-level difference between `Profit` and `Cost` for each order.
```dax
ProfitCostDifference = 'SalesData'[Profit] - 'SalesData'[Cost]
```

### 3. Calculated Measure — `TotalProfit`
Dynamically aggregates total profit earned across any active visual or slicer filter context.
```dax
TotalProfit = SUM('SalesData'[Profit])
```

## 📈 Step 3: Dashboard Visualisations

The Power BI report page brings together six interactive visuals:

| Visual Type | Title | Fields Used | Purpose |
| :--- | :--- | :--- | :--- |
| **KPI Card** | Total Profit Earned | `TotalProfit` (Measure) | Displays overall net profit across valid orders. |
| **Pie Chart** | Order Distribution by Region | Legend: `Region`<br>Values: Count of `OrderID` | Compares order volume share across North, South, East, and West regions. |
| **Clustered Column Chart** | Top 5 Trending Products | X-Axis: `Product`<br>Y-Axis: Count of `OrderID` (Top 5 Filter) | Highlights the five most frequently ordered products. |
| **Line Chart** | Profit Trend Over Time | X-Axis: `OrderDate`<br>Y-Axis: `TotalProfit` | Tracks longitudinal profit performance over time. |
| **Table Visual 1** | East Region Orders | `OrderID`, `OrderDate`, `CustomerName`, `Region`, `Product`, `Sales`, `Profit` | Displays filtered records generated by the `EastRegionOrders` DAX table. |
| **Table Visual 2** | Profit vs. Cost Spread | `OrderID`, `Product`, `Profit`, `Cost`, `ProfitCostDifference` | Audits row-level calculations from the `ProfitCostDifference` column. |

## 🚀 How to Run This Project

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Open in Power BI Desktop:**
   * Open `Sales_Analysis_Dashboard.pbix` in **Microsoft Power BI Desktop**.
   * If prompted to update the data source path, go to **Transform Data > Data source settings**, select **Change Source**, and point it to your local copy of `SalesData_1000Rows_WithIssues_copy.csv`.
   * Click **Close & Apply** to refresh the report.
